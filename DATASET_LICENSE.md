# Released Dataset Licensing

This note answers [issue #1](https://github.com/rithirn75-bot/Annoy-DataSync/issues/1) for **Annoy-PyEdu-Rs-Raw** and **Annoy-PyEdu-Rs**. Sources were checked on September 24, 2026.

## Published License Status

Neither the [Annoy-PyEdu-Rs-Raw card](https://huggingface.co/datasets/sdfeawqf/Annoy-PyEdu-Rs-Raw) nor the [Annoy-PyEdu-Rs card](https://huggingface.co/datasets/sdfeawqf/Annoy-PyEdu-Rs) specifies a standalone dataset license. Neither dataset repository contains a license file. Public availability alone does not grant unrestricted reuse rights.

## Upstream Terms

The raw dataset card describes its PythonEdu-Rs data as adopted from HuggingFaceTB. The [Python-Edu section of SmolLM-Corpus](https://huggingface.co/datasets/HuggingFaceTB/smollm-corpus#python-edu) identifies The Stack v2 as the source of its Python files and explicitly refers users there for the data license.

SmolLM-Corpus's top-level metadata lists **Open Data Commons Attribution (ODC-BY)**. That label must not be treated as a blanket license for the underlying Python source files or for Annoy-specific generated additions.

[The Stack v2 licensing information](https://huggingface.co/datasets/bigcode/the-stack-v2-train-full-ids#licensing-information) states that use of all or part of its code must comply with the original repositories' licenses, including applicable attribution requirements.

## Reuse

- Check the original license for each source or derived sample using its provenance, such as source repository and file path.
- Preserve required copyright notices, license notices, and attribution, and comply with applicable upstream terms.
- Do not assume that transformation into reasoning examples removes upstream obligations or that an unlicensed file grants reuse permission.
- Obtain clarification from the dataset maintainers for Annoy-specific generated content: the published documentation does not establish a separate license grant for that content.

This note records the available evidence; it does not grant a new license or relicense third-party material. It does not assign a license to the project code, models, or LCO benchmark.
